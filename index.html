Sync across devices

  1. Create a GitHub token. Choose Only select repositories and pick tasks-data. Under Repository permissions, set Contents to Read and write.
  2. Paste the token here and press Connect. Do this once on each device.

How it works

  • Type a task and press Enter. Keep typing to add the next one.
  • Drag a task to another day or to Later. On a phone, press and hold first.
  • Anything not done moves to today by itself, with a note of when it was first due.
  • Click a task to edit it. Clear the text to delete it.
  • The calendar button moves a task to any date.
  • Press N to start a new task for today.
